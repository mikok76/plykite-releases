# Plykite для Windows — руководство пользователя

Версия 0.9.37-win.20 (28 октября 2026). English version: [user-manual-windows.en.md](user-manual.en.md).

---

## 1. Что такое Plykite

Plykite объединяет все интернет-подключения компьютера — кабель, Wi-Fi, телефон в режиме модема по
USB или Wi-Fi, USB-модем, до восьми сразу — в одно. Он работает для всех программ Windows без
настройки в самих программах и без сервера в интернете.

- **Все программы, все соединения.** Каждое новое соединение уходит через тот канал, который сейчас
  подходит ему лучше. Выигрывают браузеры, обновления, игры, облачные диски и торренты.
- **Большие файлы быстрее.** Встроенный загрузчик Plykite качает один большой файл кусками по всем
  каналам сразу, и скорости складываются.
- **Без обрывов.** Если канал пропал, его соединения за секунды переходят на рабочие каналы.
- **Ваш выбор главнее.** Перетащите программу или сайт на канал, и они останутся на нём — навсегда,
  на час или на две минуты.
- **Честные цифры.** Каждый канал замеряется отдельно; Plykite показывает, сколько канал несёт сейчас
  и сколько может.

Одно соединение всегда идёт по одному каналу: пакеты одного соединения не делятся. Поэтому программа,
которая качает одним соединением, не получит больше скорости одного канала. Загрузчик Plykite получит:
он открывает соединения на каждом канале.

## 2. Требования

- 64-битная Windows 10 22H2 или Windows 11.
- Процессор Intel или AMD (установщик `…-x64.exe` в разделе [Releases](https://github.com/mikok76/plykite-releases/releases)). Сборка для ARM (например, Snapdragon) пока не выложена.
  Какой у вас, видно в «Параметры → Система → О системе → Тип системы».
- Права администратора для установки (один раз; Windows спросит в окне UAC).
- Хотя бы два интернет-канала, чтобы скорости складывались. С одним каналом Plykite тоже работает:
  замеряет его и ведёт статистику.

## 3. Из чего состоит Plykite

| Часть | Что делает | Права |
|---|---|---|
| **Значок у часов** и **окно Plykite** | Меню, окно, уведомления, обновления. | Ваш пользователь |
| **Контроллер** | Находит и проверяет каналы, замеряет их, решает доли, ведёт загрузки. Запускается при входе в Windows. | Ваш пользователь |
| **Служба движка** (PlykiteEngine) | Перехватывает трафик через виртуальный адаптер «Plykite» и отправляет каждое соединение через выбранный канал. Встроенный сторож выключает движок, если тот вдруг мешает интернету. | Система |

Если движок по какой-то причине остановился, интернет продолжает работать обычным путём, просто без
распределения.

## 4. Установка

1. Скачайте установщик `Plykite-Setup-<версия>-x64.exe` из последнего выпуска (Releases) и запустите его.
2. Программа пока не подписана, поэтому Windows может показать «Windows защитила ваш компьютер».
   Нажмите **Подробнее → Выполнить в любом случае**.
3. Разрешите изменения в окне UAC и пройдите шаги установщика.

Установщик сверит файлы, поставит службу движка, контроллер и значок у часов для пользователя, который
сейчас вошёл в Windows, и проверит интернет через Plykite. Если проверка не пройдёт, через 15 минут
Plykite сам вернёт обычный интернет («мёртвая рука»).

Если Defender по ошибке удалит или заблокирует `plykite.exe` (например «Bearfoos.A!ml»), установите
Plykite из zip-пакета командой `install.cmd -DefenderExclusion`: она добавит папки Plykite в исключения
Defender.

После установки у часов появится значок Plykite (если его не видно, он может быть спрятан под стрелкой
«^» рядом с часами — перетащите его на панель задач).

## 5. Первый запуск

1. Подключите каналы: кабель, Wi-Fi, телефон кабелем USB с включённым «Режимом модема» или
   «USB-модемом», USB-модем.
2. Plykite сам находит каждый канал за несколько секунд и даёт ему имя, цвет и вид (кабель, Wi-Fi,
   телефон по USB, модем). Он узнаёт и провайдера.
3. Plykite может задать вопрос о канале в меню и в окне, например, с лимитом ли трафик в новой сети, или
   не один ли провайдер у двух каналов. От ответов зависит, можно ли пускать по каналу большие загрузки.
4. Каждый канал замеряется коротким тестом. До замера в строке канала написано «ещё не измерено».

Отключённый канал исчезает из окна. Когда вы подключите его снова, он вернётся со своими настройками.

## 6. Значок у часов и его меню

Значок — логотип Plykite с цветной точкой:

| Точка | Что значит |
|---|---|
| Зелёная | Распределение работает. |
| Серая | Интернет идёт напрямую (перехват на паузе или движок выключен). Интернет есть, просто без распределения. |
| Жёлтая | Предупреждение, например работает только один канал. |
| Красная | Проблема: ни один канал не отвечает, в Windows кончились сетевые порты или движок не отвечает. |

Наведите указатель — подсказка скажет, что происходит. **Щелчок** открывает меню, **двойной щелчок** —
окно Plykite.

Меню, сверху вниз:

- **⬆ Обновить Plykite до …** — когда вышла новая версия (раздел 18). Пока срок версии подходит к концу,
  здесь же строка «Эта версия работает до …».
- **Сводка**: что происходит и что делать, с кнопкой, если она поможет (например, **Включить сейчас**
  после паузы сторожа).
- **Вопросы о новых каналах** с вариантами ответа.
- **Каналы** — по строке на канал: скорость сейчас, сколько может, задержка и состояние;
  **Измерить скорость сейчас**.
- **Загрузки**: идущие загрузки и список загрузок.
- **Активное окно: <программа>** — выбрать канал для программы, которая была впереди, и срок: навсегда,
  1 час или 2 минуты (для замера скорости).
- **Сайт в активной вкладке…** — когда впереди браузер (Chrome, Edge, Firefox и другие): выбрать канал
  для открытого сайта.
- **Перехват: включён — поставить на паузу** / **Перехват на паузе — включить**.
- **Режим по умолчанию** и **Торренты** (разделы 9 и 13).
- **Открыть Plykite…** (главный пункт), **Настройки…**, **Открыть панель в браузере…**,
  **Статистика…**; адреса панели для других устройств, если доступ включён (щелчок копирует адрес).
- **Справка**: **Проверить обновления**, **Руководство пользователя**, **Собрать журналы для отчёта об
  ошибке…**, **О программе Plykite…**.
- **Выключить Plykite (обычный интернет)** / **Включить Plykite** — останавливает или запускает службу
  движка. Выключенный Plykite не делит интернет, пока вы его не включите или не перезапустите Windows.
- **Запускать значок при входе в Windows**, **Обновить сведения**, **Выход** (закрывает только значок;
  распределение продолжает работать).

Если контроллер не отвечает, меню так и пишет и предлагает **Запустить контроллер**.

## 7. Окно Plykite

Полоса слева переключает страницы: **Обзор**, **Каналы**, **Загрузки**, **Программы**, **Сайты**,
**Назначения**, **Статистика**; внизу — **Настройки** и **Справка**. Окно следует светлой или тёмной
теме Windows; выбрать одну можно в «Настройки → Общие → Оформление». Окно запоминает свой размер и место
на каждом мониторе.

Если окно потеряло связь с контроллером, сверху появляется сообщение «Нет связи с контроллером с …»:
показанное может быть устаревшим, и все кнопки на это время выключены.

### 7.1 Обзор

Общая скорость всех каналов сейчас, график за 60 секунд по каналам и сколько все каналы могут вместе.
Ниже рисунок «нити»: каждый канал — прядь, которая входит в Plykite и выходит в интернет одной нитью;
чем быстрее канал, тем толще прядь. Наведите указатель на прядь, чтобы подсветить её; щелчок открывает
канал на странице «Каналы».

### 7.2 Каналы

Все подключённые каналы: вид, провайдер, состояние (**работает**, **основной**, **с лимитом**, **нет
интернета 3 мин**), переключатель и доля в нити. **Замерить все** проверяет каждый канал. Канал,
который вы выключили, остаётся в списке с пометкой «выключен вами» — включите переключатель, чтобы
пользоваться им снова.

В карточке канала можно переименовать его, отметить трафик с лимитом, выключить его использование,
запретить ему быть основным, задать тариф, выбрать оператора или забыть канал.

### 7.3 Загрузки

Большие файлы по всем каналам сразу (раздел 10). У готовой загрузки — **Показать в проводнике**.

### 7.4 Программы и Сайты

Каждая программа (или сайт), которая сейчас ходит в сеть, — карточка. Полоска внизу карточки показывает,
через какие каналы она идёт и в какой пропорции. **Перетащите карточку на канал**, чтобы закрепить её
там; на **Делить между всеми** — чтобы раздать по всем каналам; на **Авто** — чтобы вернуть режиму по
умолчанию. **Новое правило…** назначает программу (файл .exe) или сайт, которые сейчас не открыты.
**Почему этот канал?** в меню карточки объясняет, почему программа идёт именно так.

При назначении Plykite спрашивает срок (навсегда или на время) и что делать с уже открытыми
соединениями: **Переносить сразу** (рекомендуется: они переподключатся через новый канал), **Мягко:
только новые соединения** или **Принудительно: даже «хрупкие» программы**.

### 7.5 Назначения

Всё, что вы назначили вручную, запущено оно или нет: куда идёт (в цвете канала), сколько осталось
срока. Здесь же назначение можно снять. Ниже — программы, которые обучение отметило как «большие
загрузки», если оно включено.

### 7.6 Статистика

Трафик по часам или по дням за сегодня, 7 или 30 дней, по каналам; программы и сайты, которые больше
всего пользовались каждым каналом. Статистика строится по истории соединений, которая хранится только
на этом компьютере.

### 7.7 Настройки

Слева — оглавление (в узком окне — ссылки сверху). Изменения действуют сразу; что ждёт перезапуска
контроллера, сказано рядом.

| Раздел | Что там настраивается |
|---|---|
| Главное | Сценарий, режим по умолчанию, основной канал, порядок замены «если основной канал пропал», перехват трафика. |
| Сохранённые настройки | Ваши настройки под именем, автоматические копии, восстановление, импорт и экспорт (раздел 7.8). |
| Каналы | Для каждого канала: с лимитом, использовать, может быть основным; пакеты лимитных каналов. |
| Замер скорости | Как часто замерять каждый канал и сколько канал с лимитом может тратить в сутки. |
| Звонки и удалённый доступ | Куда идут видеозвонки, удалённый рабочий стол и интерактивные потоки. |
| Банки и входы в аккаунты / Госуслуги | Куда идут эти сайты и ждать ли свой канал при сбое. |
| DNS | Куда идут запросы имён. |
| Загрузки | Папка по умолчанию, где делятся загрузки, ограничения по каналам. |
| Торренты | Как торренты делят каналы. |
| Правила | Срок новых назначений, перенос открытых соединений, назначения по умолчанию. |
| Обучение | Автоматические правила по статистике. |
| Сбои и защита | Как быстро замечать сбой, возврат после восстановления, штраф для «мигающего» канала. |
| Доступ с других устройств | Показ панели в локальной сети, кому можно, PIN для управления. |
| История и данные | Хранить историю соединений, сколько и как долго; очистить. |
| Виртуальные машины | Как различать трафик ВМ; помощник внутри ВМ. |
| Уведомления | О каких событиях сообщать (раздел 17). |
| Общие | Оформление, язык. |
| Для специалистов | Версии, папки, журналы, **Перезапустить контроллер**. |

«Замер скорости», «Сбои и защита» и «Для специалистов» видны, когда включено **Показывать
дополнительные настройки** («Общие»). Внизу страницы — ссылка на панель в браузере.

### 7.8 Сохранённые настройки

«Настройки → **Сохранённые настройки**» хранит целые наборы ваших настроек: режим и сценарий, имена и
выбор для каналов, тарифы, назначения, загрузки и остальные настройки окна.

- **Сохранить…** запоминает текущие настройки под именем, например «Дом: кабель и два телефона».
- Plykite и сам делает копию за каждый день, когда настройки менялись, при первом запуске новой версии и
  перед каждым восстановлением. Хранятся 10 последних автоматических копий, ваши — всегда.
- **Восстановить** возвращает копию. Plykite сначала сохранит текущие настройки и через несколько секунд
  перезапустит контроллер; интернет продолжит работать.
- **Переименовать**, **Экспорт** (один файл, который можно перенести на другой компьютер — в том числе на
  Mac; в нём нет паролей, ключей, адаптеров и устройств этого компьютера) и **Удалить**. Удалённая копия
  30 дней лежит в корзине, её можно вернуть.
- **Импорт** загружает выгруженный файл; его каналы сопоставляются с каналами этого компьютера по виду.

Замеры, статистика и история соединений в копию не входят.

### 7.9 Справка

Версия и дата сборки, **срок беты** (до какого дня работает эта версия), состояние обновлений с кнопкой
**Проверить обновления**, автор, лицензия бета-версии и сторонние лицензии, **Руководство
пользователя**, **Открыть папку журналов**.

## 8. Назначение программ и сайтов

Четыре способа:

1. Перетащить карточку на страницах **Программы** или **Сайты**.
2. Меню значка → **Активное окно: <программа>** или **Сайт в активной вкладке…**.
3. **Новое правило…** на страницах «Программы» и «Сайты» (для программы, которая не запущена: выберите
   её файл .exe).
4. Командная строка: `plykite override add --app "Speedtest" --mode only-mobile --ttl 2m`.

Программа в Windows назначается по имени своего файла (например, `chrome.exe`), поэтому правило
действует и когда программа не запущена.

Варианты для канала: сначала через него, пока он работает (остальные — запасные); только через него
(соединение ждёт, если канала нет); делить между всеми каналами; «Авто» (режим по умолчанию). Срок
«2 минуты» удобен для замера скорости одного канала.

## 9. Режим по умолчанию и сценарии

Режим по умолчанию решает, что происходит со всем, что вы не назначали.

| Режим | Как работает |
|---|---|
| **Всё обычное — через основной канал; делятся только загрузки и торренты** (рекомендуется) | Сайты, видео, звонки, удалённый рабочий стол и VPN идут через основной канал — быстрый отклик. Известные загрузчики, большие параллельные загрузки и торренты делятся по всем каналам. |
| **Всё делить между всеми каналами** | Каждое новое соединение — на тот канал, который сейчас свободнее. Звонки, удалённый рабочий стол, VPN и DNS всё равно остаются на основном канале. |
| **Всё через <канал>, остальные — запасные** | Сначала один канал; остальные — только при его сбое. |
| **Только <канал>** | Всё через один канал; пока он не работает — через лучший рабочий, потом обратно. |

**Основной канал** выбирается автоматически (лучший из работающих) или закрепляется вами («Настройки →
Главное»). **Сценарии** ставят несколько настроек сразу.

## 10. Загрузка больших файлов по всем каналам

Загрузку можно начать на странице **Загрузки** или в командной строке:

```
plykite get https://example.com/big.iso -o %USERPROFILE%\Downloads
plykite get hf://org/model -include "*.safetensors"
```

- Файл режется на куски по 8 МБ; куски качаются по всем разрешённым каналам одновременно.
- Если канал пропал, его куски докачают остальные.
- Загрузка продолжается после обрыва сети, перезапуска или сна.
- Файл проверяется: по sha256 с Hugging Face или по той сумме, что вы указали (`-sha256`); если суммы
  нет — куски с разных каналов сверяются между собой.
- Целые репозитории Hugging Face качаются по `hf://org/model`.
- Загрузка уступает вашим звонкам и удалённому рабочему столу на том же канале.
- Перед большой загрузкой через канал с лимитом Plykite говорит, сколько уйдёт через него.

## 11. Замер скорости

Каждый канал замеряется коротким тестом (несколько секунд скачивания и отдачи с speed.cloudflare.com),
пока скорость не перестанет расти. Plykite повторяет замеры сам: чаще на кабеле без лимита, редко на
каналах с лимитом, в пределах суточного бюджета. **Измерить скорость сейчас** в меню или **Замерить все**
на странице «Каналы» запускают замер сразу.

## 12. Каналы с лимитом и тарифы

Отметьте канал телефона или модема как **трафик с лимитом**. Затем задайте тариф («Настройки → Каналы →
Пакет…»): гигабайты в месяц, день сброса, суточный лимит и что делать, когда тариф кончился: не пускать
загрузки и торренты, использовать только как запасной или только предупредить. Уведомления приходят на
75 % и на 100 %.

## 13. Торренты

Программы для торрентов распознаются сами. **Как торренты делят каналы**:

- **Только остаток: ваш трафик важнее** (рекомендуется) — на каждом канале торрент берёт только
  свободное;
- **На все каналы по скорости, наравне с остальным**;
- **Не на основном канале**.

Каждый пир торрента остаётся на одном канале. Для лучшего результата выключите µTP в программе для
торрентов.

## 14. Звонки, удалённый доступ, банки и госсайты

Видеозвонки (Zoom, Teams и другие), удалённый рабочий стол и терминалы по умолчанию остаются на основном
канале, чтобы переключение не оборвало разговор. Банки, входы в аккаунты (Google, Microsoft, Apple ID) и
госсайты всех стран держатся на одном канале: такие сайты выкидывают из аккаунта, когда меняется ваш
адрес. В настройках каждую группу можно отправить на любой канал.

## 15. VPN

Plykite узнаёт подключённые программы VPN (в том числе Tailscale). VPN с раздельным туннелем работает
вместе с Plykite. VPN с полным туннелем, который забирает весь трафик, заставляет Plykite отойти в
сторону, пока он подключён; меню и окно об этом пишут.

В Windows пока нет двух возможностей версии для Mac: VPN как отдельного выхода для программ и «DNS
вместе с программой».

## 16. Виртуальные машины и доступ с других устройств

Plykite находит виртуальные машины (VMware, VirtualBox, Hyper-V, WSL и другие). Если поставить внутрь ВМ
маленького помощника («Настройки → Виртуальные машины → Помощник для ВМ»), программы самой ВМ появятся
отдельными карточками. Установщик Plykite добавляет для этого одно правило брандмауэра Windows, только
для адаптеров ВМ.

«Настройки → Доступ с других устройств» показывает панель Plykite в браузере другого компьютера или
телефона в вашей сети. Без PIN гости только смотрят; с PIN могут 12 часов менять режимы и правила. На
этом компьютере панель открывается по адресу `http://127.0.0.1:1081/` или из меню.

## 17. Уведомления

Plykite показывает уведомления своего значка у часов: канал пропал или вернулся, пакет израсходован на
75 % или кончился, распределение выключилось само, сторож остановил движок. Выбор — в «Настройки →
Уведомления». Щелчок по уведомлению открывает окно.

Windows может скрывать уведомления (режим «Не беспокоить», «Параметры → Система → Уведомления»).
Поэтому самое важное — новая версия и конец срока беты — Plykite показывает ещё и первым пунктом меню и
полосой в окне.

## 18. Обновления и срок беты

Это бета-версия. Каждая сборка работает **70 дней** от даты сборки; дата окончания видна в «Справке».
Когда срок закончится, Plykite перестанет делить интернет (интернет останется обычным), пока вы не
поставите новую версию.

Раз в день Plykite сам проверяет, вышла ли новая версия (скачивается маленький подписанный файл-описание
с github.com). Когда версия вышла:

- первым пунктом меню появляется **⬆ Обновить Plykite до …**, а в окне — полоса **Обновить Plykite**;
- за 14 и за 3 дня до конца срока Plykite напоминает об этом;
- проверить сразу можно в «Справка → Проверить обновления».

Нажмите **Обновить Plykite**: установщик скачается через самый быстрый работающий канал, его размер и
контрольная сумма будут проверены, затем Windows один раз спросит разрешение. Установщик обновит Plykite;
настройки сохранятся, интернет может пропасть на несколько секунд. Сам по себе Plykite ничего не
устанавливает — только по вашему нажатию.

## 19. Конфиденциальность

- Plykite работает только на вашем компьютере, без учётной записи и без сервера. Разработчику никакие
  данные не отправляются.
- История соединений хранится только на этом компьютере; её можно выключить, ограничить и очистить в
  «Настройки → История и данные».
- Внешние службы: speed.cloudflare.com (замеры), 1.0.0.1 (проверка, что канал работает), Team Cymru
  (оператор по внешнему адресу), github.com (раз в день — проверка новой версии).
- В журналах есть имена сайтов, программ, сетевых адаптеров, сетей Wi-Fi и внешние адреса. Посмотрите
  их, прежде чем отправлять.

## 20. Если что-то не так

**Сначала посмотрите вверх меню значка** — там написано, что происходит.

| Сообщение | Что делать |
|---|---|
| «Интернет идёт напрямую…» | Сторож поставил движок на паузу, или он на паузе. Интернет работает без распределения; Plykite сам включит движок через 2, 5 или 15 минут, или нажмите **Включить сейчас**. |
| «Контроллер Plykite не отвечает» | Нажмите **Запустить контроллер** в меню, или в окне «Настройки → Для специалистов → Перезапустить контроллер». |
| В окне «Только просмотр» | Перезапуск контроллера обычно помогает; интернет при этом работает. |
| «В Windows кончились сетевые порты…» | Закройте названную программу; порты освободятся за 30–60 секунд. |
| У канала «нет интернета» | Проверьте телефон: раздача включена, мобильные данные включены, есть сигнал. |
| Нужен обычный интернет прямо сейчас | Меню → **Выключить Plykite (обычный интернет)**. Включить обратно — тем же пунктом. |

**Собрать журналы для отчёта об ошибке…** («Справка» в меню) сохраняет zip с журналами контроллера,
значка, установщика и службы и выводом `plykite diag`. Работает, даже когда контроллер не отвечает.
Журналы лежат в `%LOCALAPPDATA%\Plykite\logs` и `C:\ProgramData\Plykite\logs`.

## 21. Командная строка

Команды выполняются в PowerShell или командной строке.

| Команда | Зачем |
|---|---|
| `plykite status`, `plykite links` | Состояние каналов, доли, программы, назначения. |
| `plykite link rename\|metered\|use\|never\|forget ID …` | Изменить один канал. |
| `plykite primary [auto\|ID]`, `plykite mode …`, `plykite p2p-mode …` | Основной канал, режим по умолчанию, режим торрентов. |
| `plykite override add\|list\|rm\|clear` | Ручные назначения. |
| `plykite measure`, `plykite get …`, `plykite downloads` | Замер, загрузка, загрузки. |
| `plykite config list\|save\|restore\|export\|import` | Сохранённые настройки. |
| `plykite diag`, `plykite verify-routing` | Диагностика и живая проверка каналов. |
| `plykite pause`, `plykite resume` | Пауза перехвата. |
| `plykite agent start\|stop\|restart\|status\|log` | Контроллер. |
| `plykite service start\|stop\|status` | Служба движка (`stop` — обычный интернет). |
| `plykite version`, `plykite help` | — |

## 22. Удаление

«Параметры → Приложения → Установленные приложения → Plykite → Удалить» (или `uninstall.cmd` из
zip-пакета). Интернет сразу станет обычным. Настройки и журналы останутся; `uninstall.cmd -Purge`
удалит и их.

## 23. Ограничения

- Одно соединение всегда идёт по одному каналу; скорости складываются только у загрузок с многими
  соединениями (загрузчик Plykite, менеджеры загрузок, торренты).
- Только IPv4; трафик IPv6 не распределяется.
- Локальные сети и multicast идут мимо Plykite — так задумано.
- Нет VPN-выходов для программ и «DNS вместе с программой» (есть в версии для Mac).
- Программа не подписана: Windows SmartScreen и Defender могут предупреждать.
- Бета-версия работает 70 дней от даты сборки (раздел 18).

## 24. Лицензии

Plykite использует движок mihomo (GPL-3.0; исходники и правка лежат с программой), Wintun, среду
выполнения Go и .NET и открытые данные. Тексты лицензий — в «Справка → Сторонние лицензии» и в папке
`C:\Program Files\Plykite Setup\licenses`.
